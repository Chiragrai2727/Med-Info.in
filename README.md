# Aethelcare India

Banned Drugs Search India — Search 300+ medicines banned by CDSCO. Support for all 22 scheduled Indian languages. Access accurate medication info, generic alternatives, and safety alerts. Privacy-first Indian healthcare platform.

## Features
- **Banned Drug Search**: Instantly check if a medication is prohibited in India.
- **AI Health Guide**: Get pharmacological details and safety alerts using Gemini AI.
- **Multilingual Support**: Available in 22 scheduled Indian languages.
- **Privacy First**: Localized search and secure data handling.

## Tech Stack
- **Frontend**: React 19, TypeScript, Vite, Tailwind CSS, Motion.
- **Backend**: Netlify Functions (Node.js).
- **Database/Auth**: Firebase Firestore & Authentication.
- **AI**: Google Gemini API.

## Deployment
Deployed on **Netlify** with custom domain `aethelcare.xyz`.
